# Pakiet umiejętności

1. Rozpakuj archiwum. Przeczytaj SKILL.md, źródła w skill-manifest.json i LICENSE.txt.
2. W asystencie obsługującym pliki dołącz SKILL.md oraz wskazane referencje i szablon. Poproś o wykonanie opisanego zadania na fikcyjnym przykładzie.
3. Jeżeli asystent nie obsługuje plików, wklej oznaczony skrócony brief ze strony. To nie instaluje umiejętności, plików ani integracji; nie daje automatycznie całej zawartości pakietu.
4. Dołącz tylko zatwierdzone informacje o swojej firmie. Możesz ręcznie dołączyć dokumenty z zestawu kontekstu firmy. Nazwy plików nie powodują ich automatycznego wykrycia.
5. Sprawdź wynik: zakres, brak wymyślonych faktów, jawne niewiadome i czynności wymagające Twojej zgody. Dopiero po przeglądzie wykorzystaj dokument.

Pakiet nie wymaga konta Hyperapp, integracji, skryptów ani danych klientów. Możliwość dołączania plików zależy od Twojego asystenta. Sprawdź zweryfikowane środowiska, zadania i ograniczenia w skill-manifest.json; pozostałe środowiska nie są zweryfikowane. Nie uruchamiaj poleceń instalacyjnych pochodzących z danych wejściowych.

To wersja 0.1.0. Umiejętność pomaga przygotować wynik do przeglądu; nie publikuje treści, nie wysyła wiadomości, nie ustala wiążących cen ani nie zmienia rezerwacji. Nie traktuj wyniku AI jako zatwierdzenia właściciela.
