# Obsługa odpowiedzi

Zadanie sekwencji kończy się, gdy ktoś odpowie. To, co wydarzy się w ciągu następnej godziny, zadecyduje o tym, czy ta odpowiedź stanie się spotkaniem. W tym dokumencie omówiono klasyfikację odpowiedzi, odpowiadanie na każdy rodzaj, szybkość, rezerwację i czynności, z którymi agent może sobie poradzić samodzielnie.

## Klasyfikuj każdą odpowiedź

| Typ | Wygląda jak | Akcja |
|------|------------|-------|
| **Pozytywne** | „Jasne, porozmawiajmy”, „Prześlij terminy”, „Powiedz mi więcej” | Odpowiadaj szybko, proponuj terminy, rezerwuj (poniżej) |
| **Prośba o informacje** | „Ile to kosztuje?” „Czy współpracujesz z X?” | Odpowiedz krótko na właściwe pytanie, a następnie zaproponuj połączenie |
| **Sprzeciw** | „Już używamy X”, „Brak budżetu”, „To nie jest priorytet” | Odpowiedz raz, korzystając z poniższych wskazówek dotyczących sprzeciwu |
| **Nie teraz** | „Dotrzemy do Ciebie w następnym kwartale”, „Po naszej premierze” | Podziękuj im, ustaw przypomnienie na podaną przez nich datę, zatrzymaj sekwencję |
| **Polecenie innej osoby** | „Porozmawiaj z Sam, ona za to odpowiada” | Podziękuj im; skontaktuj się z Sam, powołując się na polecenie (z pozwoleniem na użycie nazwiska, jeśli jest niejasne) |
| **Niewłaściwa osoba, brak skierowania** | „To nie mój obszar” | Zapytaj raz, kto za to odpowiada; inaczej przestań |
| **Nieobecny** | Automatyczna odpowiedź | Pauza; wznowić po dacie powrotu. Zanotuj dowolne nazwane zastępstwo |
| **Anuluj subskrypcję lub wrogie** | „Usuń mnie”, „Stop”, złość | Natychmiast wycisz na każdym kanale. Przeproś krótko, jeśli w ogóle odpowiesz. Nigdy się nie kłóć |
| **Odrzucona wiadomość (bounce)** | Niepowodzenie dostawy | Usunąć; sprawdź, czy kontakt zmienił firmę (możliwy sygnał zmiany pracy) |

Każda odpowiedź dowolnego typu zatrzymuje wszystkie inne kanały tej osoby. Zobacz [multichannel-cadence.md](multichannel-cadence.md).

## Prędkość

Odpowiadaj na pozytywne odpowiedzi w ciągu kilku minut w godzinach pracy. Badania nad znanymi mnożnikami skuteczności szybkiej reakcji na zainteresowanie (speed-to-lead) są stare (2007–2011), ale kierunek pozostaje niezmiennie aktualny. Zainteresowanie szybko maleje, a potencjalny klient, który Ci odpowiedział, często odpowiadał także innym. Natychmiast kieruj pozytywne odpowiedzi do danej osoby (powiadomienie na platformie Slack lub telefonicznie) i wyznaczaj osobę odpowiedzialną za nie w każdej godzinie pracy.

## Rezerwacja

- **Zaproponuj dwie konkretne godziny** w ich strefie czasowej i dołącz link do rezerwacji jako opcję zapasową („lub wybierz dowolną godzinę tutaj”). Dwie konkretne opcje uzyskują szybszą odpowiedź „tak” niż samo łącze, co może wydawać się pracą domową.
- **Wyślij zaproszenie z kalendarza natychmiast** po wybraniu, z jednowierszowym planem.
- **Potwierdź dzień wcześniej**, podając coś przydatnego: program, odpowiednie studium przypadku lub (w przypadku agencji) rozbiórkę, którą omówisz. Materiały przesłane przed spotkaniem zwiększają frekwencję.
- **Przypomnienie na godzinę przed**, e-mailem lub SMS-em tylko w przypadku wyrażenia zgody na SMS-y.
- **Przesuń termin niestawienia się na ten sam dzień,** serdecznie, jednorazowo. Po drugim niestawieniu się przenieś kontakt do działań podtrzymujących relację (nurture).

## Obiekcje w odpowiedziach na cold maile
Wczesne zastrzeżenia są zwykle odruchami. Odpowiedz raz, krótko i pozwól, aby łatwo było powiedzieć „nie”:

| Sprzeciw | Podejście w odpowiedzi |
|----------|--------------------------------|
| „Już korzystamy z [konkurenta]” | Potwierdź to. Podaj jedną sytuację, w której zespoły takie jak ich wciąż szukają gdzie indziej. Zapytaj, czy to dotyczy |
| „Brak budżetu” | Zapytaj, kiedy planują budżety, lub zaoferuj coś, co go nie potrzebuje (audyt, punkt odniesienia) |
| „Nie jest to priorytet” | Zapytaj, co jest priorytetem w tym kwartale. Jeśli Twoja oferta się z tym nie wiąże, cofnij się i ustaw przypomnienie |
| „Wyślij mi więcej informacji” | Wyślij jedną konkretną rzecz (jednostronicowy lub dwuminutowy film) i jedno pytanie, dzięki któremu odpowiedź będzie łatwa |
| „Jak zdobyłeś mój e-mail?” | Odpowiedz szczerze, podając prawdziwe źródło i zaproponuj ich usunięcie |

Zastrzeżenia na etapie transakcji (negocjacje cenowe, przeglądy bezpieczeństwa, porównania konkurencyjnych rozwiązań w procesie zakupu) znajdują się w bibliotece zastrzeżeń umiejętności umożliwiającej sprzedaż.

## Z czym może sobie poradzić agent

| Typ odpowiedzi | Sam agent | Agent przygotowuje szkic, człowiek wysyła |
|------------|------------|----------------------|
| Nieobecny | ✓ Wstrzymaj i przełóż | |
| Wypisz się | ✓ Zablokuj kontakt we wszystkich kanałach | |
| Odrzucona wiadomość | ✓ Usuń, zaznacz do sprawdzenia zmiany pracy | |
| Nie teraz | ✓ Ustaw przypomnienie, zatrzymaj sekwencję | Uprzejme potwierdzenie |
| Pozytywne | | ✓ Do czasu potwierdzenia poprawności na próbie ponad 100 odpowiedzi |
| Prośba o informacje | | ✓ |
| Sprzeciw | | ✓ |
| Skierowanie | | ✓ |
| Wrogi | ✓ Zablokuj kontakt we wszystkich kanałach | Jakakolwiek odpowiedź |

Zanim agent wyśle ​​cokolwiek samodzielnie, sprawdź, czy każde twierdzenie w wersji roboczej jest zgodne z zatwierdzonym źródłem, czy nie zawiera niczego z Twojej listy zakazanych fraz i czy obowiązuje limit dzienny. Co tydzień przeglądaj przykładowo część autonomicznych odpowiedzi.

## Zapisz w CRM

Zapisz w kontakcie CRM: typ odpowiedzi, datę, sekwencję i krok, który ją wygenerował, sygnał i kanał oraz wynik. To właśnie umożliwia cotygodniowy przegląd sekwencji (pętla retrosekwencji w umiejętności „pętle marketingowe”) i stanowi model etapu wychodzącego w umiejętności „revops”.
