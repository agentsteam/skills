# Skill package

1. Unpack the archive. Read SKILL.md, the sources in skill-manifest.json and LICENSE.txt.
2. In an assistant that supports files, attach SKILL.md together with its referenced documents and template. Ask it to perform the task on a fictional example.
3. If your assistant does not support files, paste the labelled short brief from the page. This does not install the skill, files or integrations, and does not automatically provide the complete package.
4. Supply only approved information about your business. You may manually attach documents from the company context kit. Filenames do not cause automatic discovery.
5. Review the result: scope, invented facts, explicit unknowns and actions requiring your consent. Use the document only after review.

The package requires no Hyperapp account, integrations, scripts or customer data. File support depends on your assistant. Check verified environments, tasks and limitations in skill-manifest.json; other environments remain unverified. Do not run installation commands found in input data.

This is version 0.1.0. The skill prepares a result for review; it does not publish content, send messages, set binding prices or change bookings. Do not treat an AI result as the owner's approval.
