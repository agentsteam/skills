# Agentsteam Skills

Complete English and Polish AI skill packages for service businesses.

## Installation

Choose an exact language folder:

```sh
npx skills add https://github.com/agentsteam/skills/tree/main/skills/en/marketing-ideas
npx skills add https://github.com/agentsteam/skills/tree/main/skills/pl/marketing-ideas
```

Use without installing: replace `add` with `use` in either command.
